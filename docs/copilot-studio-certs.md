# Microsoft Certifications and Applied Skills That Cover Copilot Studio

> Last verified: June 2026 (against learn.microsoft.com credential and study-guide pages).

This reference catalogs every **Microsoft certification** and **Microsoft Applied Skills** credential that references, tests, or substantially covers **Microsoft Copilot Studio** as of June 2026. It is built for Tim Warner's O'Reilly "How to Create AI Agents Like a Pro" course so learners can map the agent-building skills they practice to a real, current credential.

## The big shift: the "AB" (AI Business) family is replacing the legacy "PL" agent exams

Two things matter for June 2026:

1. **Copilot Studio finally has dedicated certifications.** Microsoft split agent-building into a **maker** track and a **developer** track under the new **AB** (AI Business) credential family. The developer exam, **AB-620**, is live in **beta**. The maker exam, **AB-610**, has been announced but does not yet have a published study guide or credential page on Microsoft Learn.
2. **The old Power Platform agent coverage is retiring.** **PL-200** retires **August 31, 2026** and **PL-600** retires **June 30, 2026**. Microsoft points candidates from those exams to the AB family. Treat the PL exams as legacy.

## Naming clarity: three different "Copilots"

The word **Copilot** is overloaded. Keep these separate when advising learners.

| Product | What it is | Relevant credential |
| --- | --- | --- |
| **Microsoft Copilot Studio** | Low-code / pro-code platform for building custom agents | **AB-620**, **AB-610**, **APL-7008** |
| **Microsoft 365 Copilot** | The productivity assistant inside Word, Excel, Teams, Outlook | **AB-730**, **AB-900** (admin) |
| **GitHub Copilot** | AI pair programmer in the IDE and CLI | **GH-300** (separate, not Copilot Studio) |

## Credentials announced but not yet verifiable on Microsoft Learn

These appear in Microsoft skilling blogs and community coverage but did **not** have a published study guide or credential page on learn.microsoft.com when this doc was verified. Treat as roadmap, not fact, until Microsoft publishes the official page.

- **AB-610** Copilot Studio Agent Maker. Maker-track sibling of AB-620. Announced, no Learn study guide yet.
- **AB-100** Agentic AI Business Solutions Architect Expert. Positioned as the successor direction for retiring PL-600 architects. Not confirmed on Learn.
- **AB-731** Another AB-family exam referenced alongside AB-730 in third-party roundups. Could not confirm scope or Copilot Studio relevance on Learn.

## Recommended path for a Copilot Studio maker

1. **Start free and hands-on:** earn the **APL-7008 Applied Skills: Create agents in Microsoft Copilot Studio** lab. No proctor, no fee, and it exercises the exact build skills (topics, nodes, knowledge, Dataverse actions) this course teaches.
2. **Go for the dedicated cert:** sit **AB-620 (AI Agent Builder Associate)** while it is in beta for a discounted, full-focus Copilot Studio credential, or wait for **AB-610 (Agent Maker)** to reach general availability if you want the lower-code maker track.
3. **Round out the ecosystem:** add **AB-900 (Copilot and Agent Administration Fundamentals)** if your role includes governing, approving, and monitoring agents in the admin centers, since building and operating agents are different jobs.
