## Overview
Microsoft Copilot Studio has revolutionized how business users create AI-powered automation. No longer do you need developers to build intelligent agents that handle customer inquiries, automate approvals, or process documents. With Copilot Studio's graphical interface, you can describe what you want in plain language and watch as AI builds your agent, complete with knowledge sources, actions, and autonomous triggers that work while you sleep.

This hands-on course takes you from zero to deployed agent in four hours. You'll build three production-ready agents: a customer service assistant that answers from your knowledge base, an employee onboarding agent that automates repetitive HR tasks, and an autonomous document processor that triggers file uploads. By the session's end, you'll have the skills and templates to automate dozens of business processes that currently eat up your team's time. This is AI automation for power users who need results, not code.

## What You'll Learn
By the end of this live online course, you'll be able to:
- Create conversational agents using natural language that connect to your organization's data.
- Configure autonomous triggers so agents respond to events like emails, documents, or data changes.
- Publish agents across channels including Teams, SharePoint, and Microsoft 365 Copilot.
- Measure agent effectiveness using built-in analytics to prove ROI and optimize performance.

## Schedule
The time frames are estimates and may vary according to how the class is progressing.

### Segment 1: Copilot Studio Fundamentals & Creating Your First Agent (50 minutes)
- Clearing the confusion: "Agents" in Microsoft's world.
- Understanding when to use Copilot Studio agents vs. other automation tools.
- Navigating Copilot Studio: home, create, analytics dashboards.
- Demo: Building your first agent using natural language description.
- Adding knowledge sources: SharePoint, OneDrive, websites, documents.
- Testing conversations in the simulator and refining responses.
- Mini-exercise: Create a simple FAQ agent for your department.
- Q&A (5 minutes).

**Break (10 minutes)**

### Segment 2: Topics, Actions, and Power Automate Integration (50 minutes)
- Understanding topics: triggers, conversation paths, entities.
- Adding prebuilt actions: email, approvals, data updates.
- Demo: HR onboarding agent with approval workflows.
- Connecting to Power Automate for advanced actions.
- Variables and decision logic without coding.
- Mini-exercise: Add an action to your agent.
- Q&A (5 minutes).

**Break (10 minutes)**

### Segment 3: Autonomous Agents & Event Triggers (50 minutes)
- Introduction to autonomous agents in Copilot Studio (preview feature).
- Setting up event triggers: email arrival, file creation, data changes.
- Demo: Document processor agent that runs automatically.
- Activity tracking and monitoring agent behavior.
- Security and governance considerations.
- Mini-exercise: Configure a trigger for your scenario.
- Q&A (5 minutes).

**Break (10 minutes)**

### Segment 4: Deployment, Analytics, and ROI (50 minutes)
- Publishing to Teams and SharePoint.
- Extending Microsoft 365 Copilot with your agents.
- Understanding agent analytics: sessions, satisfaction, topics.
- Measuring impact: agent-assisted hours and cost savings.
- Governance: sharing controls and data policies.
- Building your automation roadmap.
- Wrap-up exercise: Identify three processes to automate next.
- Q&A (5 minutes).

**Overall wrap-up and next steps (5 minutes)**
